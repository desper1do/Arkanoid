Что изменилось с прошлой версии:

1. Модель больше не зависит от Controllers и Views

	- Доработана структура MVC
	- Создан новый проект с тестами для GameModel, проверяющий работу уровней, движения мяча и активацию читов.


2. Добавлен бесконечный режим игры

	- В GameController добавлен параметр _isEndless и логика для генерации новых блоков после завершения уровня.
	- В MainMenuController добавлена кнопка и обработчик для запуска бесконечного режима (OnEndlessClicked).
	- В GameModel добавлен метод GenerateRandomBlocks() для генерации случайных блоков в бесконечном режиме.


3. Изменения в GameController

	- Конструктор теперь принимает параметр isEndless.
	- Добавлена проверка if (_isEndless) в метод UpdateGame для обработки бесконечного режима.
	- Чит-код в бесконечном режиме не начисляет максимальный счет.


4. Изменения в GameModel

	- Добавлен параметр isEndless в конструктор.
	- Реализован метод GenerateRandomBlocks() для создания случайных блоков.
	- Логика активации читов изменена для учета бесконечного режима.


5. Изменения в MainMenuView:

	- Добавлена кнопка "Бесконечный режим" и событие EndlessClicked.
