Что изменилось с прошлой версии:

1. Структура проекта

Проект был реорганизован по принципу MVC (Model-View-Controller):
	- Models: Классы игровых объектов (Ball, Paddle, Block, GameModel, GameProgress);
	- Views: Формы (GameView, LevelSelectionView, MainMenuView);
	- Controllers: Логика управления (GameController, LevelSelectionController, MainMenuController).


2. Физика мяча

В классе Ball была полностью переработана физика:
	- Добавлен угол отскока от платформы (BounceFromPaddle), который зависит от точки удара;
	- Реализован нормализованный вектор скорости (NormalizeVelocity);
	- Добавлены методы для установки скорости и позиции мяча (SetVelocity, SetPosition).


3. Управление игрой

	- Добавлена пауза (клавиша P);
	- Мяч теперь "прилипает" к платформе до нажатия клавиши Up.


4. Звуки

	- Звуки теперь загружаются из папки sounds;
	- Добавлена очередь воспроизведения звуков для избежания наложений.


5. Уровни

	- Уровни теперь генерируются на основе шаблонов (символы ■ и · в levelPatterns);
	- Каждый уровень имеет уникальный дизайн блоков.


6. События

Добавлены события для взаимодействия между View и Controller:
	- PaddleMoveRequested, CheatCodeEntered, RestartRequested, PlayClicked, LevelsClicked, ExitClicked;
	- В GameModel добавлено событие LifeLost для обработки потери жизни.


7. Улучшения кода

	- Добавлено освобождение ресурсов (Dispose для GameController);
	- Улучшена обработка столкновений мяча с блоками и платформой;
	- Удалено дублирование кода (например, инициализация игры вынесена в метод Reset).
