# Arkanoid

Игра в жанре арканоид на C# WinForms. Индивидуальный учебный проект по дисциплине «Программирование на C#», 2-й семестр УрФУ.

## Об игре

Классический арканоид: управляй платформой, отбивай мяч и разбивай блоки. Несколько уровней с разными конфигурациями блоков, система жизней, счёт и звуковые эффекты.

**Управление:**
| Клавиша | Действие |
|---------|----------|
| `← →` | Движение платформы |
| `↑` | Запуск мяча (если прилип к платформе) |
| `P` | Пауза |
| `end` (набрать) | Чит: автоматически завершить уровень |

## Стек

- **Язык:** C#
- **Платформа:** .NET Framework 4.7.2
- **UI:** Windows Forms (WinForms)
- **Архитектура:** MVC (Controllers / Models / Views)

## Структура проекта

```
Arkanoid/
  Controllers/   # GameController, LevelSelectionController, MainMenuController
  Models/        # Ball, Paddle, Block, GameModel, GameProgress
  Views/         # Формы WinForms + FontManager
  Resources/     # Звуки (.wav), шрифт PressStart2P
```

## Запуск

Открыть `Arkanoid.sln` в Visual Studio 2022, собрать и запустить (F5).

Требуется: Windows, .NET Framework 4.7.2.
